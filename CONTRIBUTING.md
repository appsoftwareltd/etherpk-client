# Contributing

## Issues

Bug reports and feature requests are welcome as GitHub issues. For a bug, include the version (the
release tag, or the image tag you run), how you deploy it (Docker image, Node bundle, or built from
source), what you did, and what happened instead.

Report a security vulnerability privately, as [SECURITY.md](SECURITY.md) describes, never in a
public issue.

## Pull requests

Pull requests are not merged in this repository. It is a one-way copy of App Software's private
EtherPK repository: every change there is exported here as a new commit that replaces the tree, so
a commit made here directly would be overwritten by the next export.

A change worth having is applied in the private repository instead, crediting you with a
`Co-authored-by:` line, and arrives here with the next export. Open an issue describing the change,
or link a fork that shows it.
